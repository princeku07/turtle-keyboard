This package vendors a Java port of the SymSpell algorithm:

  Source:  https://github.com/Lundez/JavaSymSpell
  License: MIT
  Author:  Hampus Londögård (2018)

Original SymSpell (C#):

  Source:  https://github.com/wolfgarbe/SymSpell
  License: MIT
  Author:  Wolf Garbe (2018)

Only mechanical changes were applied during vendoring:

  1. The package declaration in each file was rewritten from
     `package SymSpell;` to
     `package com.prince.turtlekeyboard.suggest.symspell;`.

  2. The intra-package import in ChunkArray.java was updated to the new
     package path.

  3. In SymSpell.java, four `System.out.println(ex.getMessage())` sites
     were swapped for `android.util.Log.w("SymSpell", ..., ex)` so error
     output goes to logcat on Android.
